# Лабораторная работа №1 — Усеченный правильный тетраэдр (вариант 4)

Простое приложение на C++ с Vulkan, GLFW и ImGui. Рисует усечённый правильный
тетраэдр (4 шестиугольные и 4 треугольные грани) в реальном времени.

## Что реализовано

Базовое задание:
- Vulkan + GLFW окно, графический конвейер с depth-test
- Геометрия усечённого тетраэдра (12 вершин, индексный буфер)
- Uniform-буфер с матрицами model/view/proj, обновляется каждый кадр
- ImGui интерфейс поверх сцены

Дополнительные задания (1–5):
1. Переключение проекции (перспективная / ортографическая) — радиокнопки в ImGui
2. Позиция, поворот и масштаб фигуры регулируются слайдерами
3. Анимация движения по круговой траектории: пауза/воспроизведение, скорость, радиус
4. Выбор цвета фигуры через ColorEdit4
5. Процедурный цвет вершин (зависит от локальных координат), который умножается
   на выбранный в интерфейсе цвет — реализовано в вершинном шейдере

Пункт 6 (несколько объектов, несколько наборов дескрипторов) не реализован —
он не входит в первые пять дополнительных заданий.

## Требования

- CMake >= 3.20
- Vulkan SDK (нужен `glslc` в PATH и переменная `VULKAN_SDK`)
- Компилятор с поддержкой C++17
- Интернет при первой сборке (CMake скачает GLFW, GLM и Dear ImGui через FetchContent)

## Сборка

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release -j
```

## Запуск

```bash
./build/lab1        # Linux/macOS
build\Release\lab1.exe   # Windows
```

Шейдеры компилируются автоматически при сборке в `build/shaders/*.spv`,
приложение подхватывает их по абсолютному пути (через макрос `SHADER_DIR`),
поэтому запускать можно из любой директории.

## Управление

Всё управление находится в окне ImGui "Lab 1 controls":
- Projection — переключение перспективной/ортографической проекции
- Transform — позиция, поворот, масштаб фигуры
- Color — цвет тонирования
- Trajectory animation — воспроизведение движения фигуры по кругу, скорость, радиус
